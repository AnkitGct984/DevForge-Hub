# Tic Tac Toe Project

Files
- `TTT.html` — game UI and entry point.
- `c.css` — game styles.
- `c.js` — game logic (vanilla JS).

How to run
- Serve the folder or open `TTT.html` in a browser. The UI requires `c.css` and `c.js` to be in the same folder (already linked in `TTT.html`).

Notes
- The game maintains scores in memory while the page is open.
- Modal shows when someone wins or on draw.

Troubleshooting
- If cells don't react, open browser console for JS errors (press F12). Ensure `c.js` loaded (network tab).
- Styles are provided in `c.css`; if layout breaks, check for missing CSS link or caching.
