# Landing Page Project

Files
- `landingpage.html` — main landing page entry point.
- `landingpage.css` — styles for the hero section, feature cards, about section, and footer.

How to run
- Open `landingpage.html` in a browser, or serve the project folder and visit `/landingpage.html`.

What it includes
- A modern hero section with a bold headline and call-to-action buttons.
- Feature cards for services and value propositions.
- An about section with supporting highlights and trust signals.
- A contact section and footer with social links and contact details.

Tech stack
- Plain HTML and CSS.
- No external libraries or build step required.

Customization tips
- Edit the text and links inside `landingpage.html` to change the brand message.
- Update colors, spacing, and layout in `landingpage.css` to match your preferred style.
- Replace the email, phone, and social links in the footer with your own contact details.
